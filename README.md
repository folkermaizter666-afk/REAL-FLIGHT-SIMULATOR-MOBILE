# REAL FLIGHT SIMULATOR MOBILE

Prototipo inicial para Godot 4.3, pensado para Android y optimización en dispositivos de entrada como OPPO A53 (4 GB RAM / Snapdragon 460).

## Qué incluye esta primera base
- Escena 3D generada por código (pista, terreno y avión placeholder).
- Cámara de cabina y cámara exterior intercambiables.
- Controles táctiles de potencia, batería, motores, tren, flaps y piloto automático.
- Indicaciones básicas de velocidad, altitud y rumbo.
- Renderizador Compatibility / OpenGL para ampliar compatibilidad móvil.

## Importante
Este proyecto es un **prototipo educativo**, no un simulador certificado ni un sistema apto para entrenamiento aeronáutico. La geometría del avión y la física son provisionales. No incluye todavía un modelo 3D auténtico del Boeing 737-800 ni sistemas de aviónica reales.

## Abrir el proyecto
1. Instala Godot 4.3 o una versión 4.x compatible en una computadora.
2. Descomprime el proyecto.
3. En Godot, selecciona Importar y abre `project.godot`.
4. Ejecuta el proyecto con F6/F5.

## Android
La exportación Android requiere Godot Export Templates, Android SDK, JDK y una configuración de firma. El proyecto todavía no incluye un APK compilado.
